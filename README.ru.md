# TuneQueue

**Сонг-реквесты для Twitch на Spotify. Без Premium, без API-ключей, без серверов.**

> 🇬🇧 [In English](README.md)

## Как работает

Зритель пишет в чат Twitch `!sr <ссылка>` → расширение — прямо в открытой вкладке
open.spotify.com — нажимает собственную кнопку Spotify **«Добавить в очередь»**, и трек
встаёт в общую очередь аккаунта: играет там, где слушает стример, в браузере или в
приложении Spotify. После этого бот отвечает в чате:
`@user Queued [Artist - Track]`.

- **Spotify Premium не нужен** — обычная кнопка «Добавить в очередь» бесплатная.
- **Фокус не воруется** — вся автоматизация работает в фоновой вкладке, окно не поднимается.
- **Без серверов и ключей** — чат подключается напрямую, токен хранится локально.

## Установка

См. **[extension/README.md](extension/README.md)** — установка за минуту плюс разовая
авторизация Twitch (кнопка «Authorize Twitch»).

## Команда в чате

```
!sr https://open.spotify.com/track/…
```

Вся схема в одной команде: кулдаун 15 секунд на зрителя, запросы обрабатываются
строго по порядку.
