# TuneQueue Desktop 🎧

**Сонг-реквесты для Twitch на Spotify — без API, без Premium, без серверов.**

Скачиваешь приложение → вводишь ник канала → зрители пишут `!sr <ссылка>` в чат →
треки играют у тебя в Spotify по очереди. Приложение само читает чат Twitch
(открытый чат на рабочем столе не нужен) и само управляет локальным плеером.

## Как это работает

| Кусок | Реализация |
|---|---|
| Чтение чата Twitch | Прямое подключение к IRC Twitch по WebSocket, анонимно — без браузера и без ключей |
| `!sr <ссылка>` | Принимаются только ссылки `open.spotify.com/track/…` (и `spotify:track:…`) |
| Очередь | Живёт в приложении: порядок, кто заказал, история, кулдаун 15 сек на юзера, лимит 100 |
| Управление Spotify | Локально: протокол `spotify:track:ID` запускает трек в установленном клиенте. **Ни одного запроса к Spotify API** |
| «Что сейчас играет» | Windows SMTC (System Media Transport Controls) через PowerShell — системный механизм Windows, без Spotify API |
| Конец трека / скип | Приложение замечает смену трека в SMTC: доиграл → ставит следующий запрос; стример скипнул вручную → тоже ставит следующий |
| Ответы в чате | Опционально: бесплатный вход Twitch (Device Code) — отвечаем от имени стримера. Без входа команды выполняются молча |

## Установка и запуск (пользователю)

1. Возьми установщик `TuneQueue-…-setup.exe` (или portable) со страницы **Releases**
   репозитория на GitHub (появится после публикации — тег `v*` собирает его автоматически
   через GitHub Actions). Пока репозиторий не опубликован — собери сам: `npm run dist` на Windows.
2. Установи / запусти.
3. Введи ник своего Twitch-канала → **Подключить**.
4. Нажми ▶ **Автоплей очереди** (включён по умолчанию) — всё, зрители могут писать `!sr`.

Требования: Windows 10/11, установленный клиент Spotify (учётка любая, Premium не нужен).

## Ответы бота в чате (опционально)

Без этого блока приложение молчит, но выполняет команды. Чтобы бот писал от твоего имени:

1. На [dev.twitch.tv/console/apps](https://dev.twitch.tv/console/apps) создай приложение (бесплатно, ~1 минута).
   Redirect URI: любой, например `http://localhost` — для Device Code он не используется.
2. Скопируй **Client ID** в настройки TuneQueue → **Войти через Twitch**.
3. Откроется страница Twitch — введи показанный код, подтверди.

Токен хранится локально в `%APPDATA%\TuneQueue\config.json`.

## Сборка из исходников

```bash
cd desktop
npm install
npm run typecheck   # типы
npm test            # тесты ядра
npm run build       # сборка в build/
npm run dev         # запуск в режиме разработки (с DevTools)
npm run dist        # установщик Windows (нужна Windows либо wine)
```

### GitHub Actions

Workflow `.github/workflows/desktop-release.yml` на теге `v*` собирает установщик
на windows-latest и публикует релиз автоматически:

```bash
git tag v0.1.0 && git push origin v0.1.0
```

## Ограничения (честно)

- **Только Windows** в первой версии (driver'ы под macOS/Linux — в планах).
- Реклама free-тарифа Spotify будет проигрываться — приложение её не пропускает.
- Пропуск — только вручную в плеере (так и задумано): кнопка Next в Spotify/медиа-клавиши.
- Если Spotify закрыт — первый запрос откроет его протоколом `spotify:` (обычно без воровства фокуса; проверь у себя).
- Названия треков в очереди подтягиваются из публичного oEmbed (без ключей); без сети показывается ссылка.

## Структура

```
desktop/
  src/
    shared/types.ts      # общие типы и IPC-контракт
    main/
      index.ts           # Electron: окно, трей, IPC, команды чата
      irc.ts             # подключение к чату Twitch (анонимно или с токеном)
      twitchAuth.ts      # Device Code вход
      queue.ts           # очередь + парсер ссылок + кулдауны
      serving.ts         # конечный автомат раздачи в плеер
      oembed.ts          # подписи треков (best-effort)
      player/smtc.ts     # чтение плеера через Windows SMTC (PowerShell)
      player/windows.ts  # драйвер: запуск трека по протоколу spotify:
    preload.ts           # мост main ↔ renderer
    renderer/            # UI (vanilla TS + CSS)
  tests/                 # node:test — парсеры, очередь, SMTC, раздача
```
